## 2025-06-08 - [Hardcoded Secret Key]\n**Vulnerability:** A hardcoded synchronization secret key was found in `server.ts` and `server/db.ts` (`'ZenithNihongoSyncSecret2026'`).\n**Learning:** Default values used as fallback for secrets act as hardcoded secrets and defeat the purpose of using environment variables. Any default used if the environment variable is not set should not be valid for production authentication/authorization.\n**Prevention:** Remove fallback default secrets. If an environment variable is required, throw an error at startup if it's missing, rather than silently using an insecure default.

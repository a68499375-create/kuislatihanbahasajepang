## 2024-06-08 - [Frontend Performance: Unnecessary re-evaluation]\n**Learning:** In `src/App.tsx`, `allDictionaryEntries` and `filteredDictionary` are computed on every render of the `App` component, which is a massive anti-pattern for performance since `kanaData` is static and the dictionary size is large. The `App` component has 100+ state variables and re-renders frequently.\n**Action:** Use `useMemo` to memoize the creation of `allDictionaryEntries` and `filteredDictionary` to avoid repeating this expensive flattening and filtering on every render.
